# 😂 Joke API

A simple and interactive **RESTful Joke API** built with **Node.js and Express.js**.

The project allows users to view, create, edit, and delete jokes through a web interface. The frontend communicates with the backend using **Axios**, while **EJS** is used for dynamic page rendering.

## ✨ Features

- 📖 View all jokes
- 🔍 Get a single joke by ID
- ➕ Create new jokes
- ✏️ Edit existing jokes
- 🗑️ Delete jokes
- 🔄 Full CRUD functionality
- 🌐 RESTful API endpoints
- 💻 Simple and responsive web interface
